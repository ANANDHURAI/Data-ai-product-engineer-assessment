# Task 2 - Data Pipeline

Built an end-to-end weather data pipeline using the Open-Meteo API and Google BigQuery.

Pipeline flow:

```text
Open-Meteo API
        ↓
Python Fetch Script
        ↓
Data Transformation
        ↓
BigQuery
        ↓
SQL Analysis Query
```

Features implemented:
- API data fetching
- error handling
- logging
- data transformation
- derived analytical fields
- BigQuery integration
- SQL aggregation queries
