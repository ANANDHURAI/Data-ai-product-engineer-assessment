# Scope Definition

## Included in V1

- Dashboard overview
- Channel performance comparison
- Daily/weekly metrics
- CSV upload support
- Summary cards for:
  - spend
  - clicks
  - conversions
  - ROI

---

## Not Included in V1

- AI recommendations
- Real-time streaming data
- Client-facing portal
- Advanced forecasting
- User authentication system

---

## Why These Are Excluded

The goal of V1 is to keep the product simple, fast, and easy to adopt.

Adding advanced features too early increases complexity and slows development.
