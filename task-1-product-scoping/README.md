# Task 1 - Product Scoping

This task focuses on designing a simple internal tool for marketing performance analysis.

The goal is to reduce manual reporting effort and provide faster, more reliable insights across marketing channels.

## Included Files

- product_brief.md
- scope.md
- user_flow.md
- flow-diagram.png

## Approach

I focused on:
- simplicity
- usability
- realistic v1 scope
- reducing operational complexity

Instead of proposing a large platform, I designed a lightweight internal dashboard that integrates into the team's current workflow.


## Tradeoffs Considered

I intentionally focused on a lightweight internal tool instead of a large platform.

This approach:
- reduces complexity
- speeds up adoption
- minimizes operational overhead
- aligns better with the team's current workflow
